Ошибка возникла **после смены сервера**. Unity приложение пытается подключиться к payment gateway для эквайринга через FreedomPay, но получает ошибку о недоступности endpoint.

Проанализирована полная структура Django проекта:
- **Backend:** Django 4.2+ с PostgreSQL
- **Payment Gateway:** Отдельное приложение для интеграции с FreedomPay
- **Deployment:** Docker Compose с Nginx, PostgreSQL, Redis
- **Infrastructure:** VDS с IP 89.39.95.247 и доменом admin.comeback.uz

- ✅ `payment_gateway/views.py` - основная логика API
- ✅ `payment_gateway/urls.py` - маршрутизация

- ✅ `comeback_admin/settings.py` - настройки Django

### 3. Выявленные проблемы

#### Проблема #1: Жестко заданные URL в коде
**Файл:** `payment_gateway/views.py`, строка 27

**Было:**
```python
SITE_URL = "http://89.39.95.247"  # Захардкожено!
MERCHANT_ID = "552170"
SECRET_KEY = "wUQ18x3bzP86MUzn"
```

**Проблема:** 
- URL нельзя изменить без редактирования кода
- Нет поддержки HTTPS
- Нет разделения настроек для development/production

#### Проблема #2: Несоответствие протоколов
**Nginx конфигурация:**
- Домен `admin.comeback.uz` перенаправляет HTTP → HTTPS (строка 53)
- IP `89.39.95.247` работает по HTTP без редиректа

**Код использует:**
- `http://89.39.95.247` (HTTP)

**Unity может ожидать:**
- `https://admin.comeback.uz` (HTTPS после смены сервера)

#### Проблема #3: Отсутствие диагностических endpoints
- Нет способа проверить доступность сервера из Unity
- Нет способа получить актуальные endpoints динамически
- Сложно диагностировать проблемы подключения

#### Проблема #4: Отсутствие гибкости конфигурации
- Все настройки в коде, не в переменных окружения
- Невозможно быстро переключаться между серверами
- Сложно поддерживать несколько окружений

### Внесенные изменения

#### 1. Гибкая конфигурация URL (`payment_gateway/views.py`)

**Добавлено:**
```python
from decouple import config

# Конфигурация из переменных окружения
SITE_URL = config('SITE_URL', default='http://89.39.95.247')
SITE_DOMAIN = config('SITE_DOMAIN', default='admin.comeback.uz')
USE_HTTPS = config('USE_HTTPS', default=False, cast=bool)
MERCHANT_ID = config('FREEDOMPAY_MERCHANT_ID', default="552170")
SECRET_KEY = config('FREEDOMPAY_SECRET_KEY', default="wUQ18x3bzP86MUzn")

def get_base_url():
    """Автоматически определяет правильный URL"""
    protocol = 'https' if USE_HTTPS else 'http'
    if SITE_DOMAIN and SITE_DOMAIN != 'admin.comeback.uz':
        return f"{protocol}://{SITE_DOMAIN}"
    return SITE_URL
```

**Преимущества:**
- ✅ Легко менять настройки через .env
- ✅ Поддержка HTTP и HTTPS
- ✅ Автоматическое определение протокола
- ✅ Разделение настроек для разных окружений

#### 2. Новые диагностические endpoints

**Health Check** (`/payment-gateway/api/unity/health/`):
```python
@csrf_exempt
@require_http_methods(["GET"])
def unity_health_check(request):
    """Проверка доступности сервера"""
    return JsonResponse({
        'success': True,
        'status': 'healthy',
        'server_time': timezone.now().isoformat(),
        'base_url': get_base_url(),
        'endpoints': {
            'create_payment': f'{base_url}/payment-gateway/api/unity/create-payment/',
            'check_status': f'{base_url}/payment-gateway/api/unity/check-status/'
        }
    })
```

**Server Info** (`/payment-gateway/api/unity/server-info/`):
```python
@csrf_exempt
@require_http_methods(["GET"])
def unity_server_info(request):
    """Получение полной информации о конфигурации"""
    return JsonResponse({
        'success': True,
        'server_info': {
            'base_url': get_base_url(),
            'domain': SITE_DOMAIN,
            'use_https': USE_HTTPS
        },
        'endpoints': {...},
        'freedompay': {
            'merchant_id': MERCHANT_ID,
            'success_url': f'{base_url}/payment-gateway/freedompay/success/',
            'fail_url': f'{base_url}/payment-gateway/freedompay/fail/'
        }
    })
```

**Преимущества:**
- ✅ Unity может проверить доступность сервера
- ✅ Автоматическое получение актуальных endpoints
- ✅ Упрощенная диагностика проблем

## 📝 ВЫВОДЫ

### Причина проблемы
После смены сервера Unity приложение продолжало использовать жестко заданный старый URL (`http://89.39.95.247`), в то время как сервер переехал на домен `admin.comeback.uz` с HTTPS.

### Решение
Внедрена гибкая система конфигурации через переменные окружения с автоматическим определением протокола и поддержкой диагностических endpoints.
